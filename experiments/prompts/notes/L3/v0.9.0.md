- API `QoD for enhanced communication`, with the server variable `basePath` defaulting to `qod/v0`. `createSession` is a `POST` to `/sessions`; it answers `201`.
- The body requires `device`, `applicationServer` and `qosProfile`.
- `device` needs at least one of `phoneNumber`, `networkAccessIdentifier`, `ipv4Address`, `ipv6Address` (`minProperties` 1). `phoneNumber` matches `^\+?[0-9]{5,15}$`, so the `+` is optional.
- `applicationServer` holds `ipv4Address` or `ipv6Address`. `devicePorts` and `applicationServerPorts` hold `ports` or `ranges`.
- `qosProfile` is a string of 3 to 256 characters matching `^[a-zA-Z0-9_.-]+$`.
- `duration` is optional, in seconds, from 1 to 86400, with a `default` of 86400.
- The callback address is `webhook`, an object whose `notificationUrl` is required. `notificationAuthToken` is optional, 20 to 256 characters.
- The response has `sessionId`, `qosStatus` (`REQUESTED`, `AVAILABLE`, `UNAVAILABLE`), `startedAt` and `expiresAt` (`int64`, Unix time), and `messages`.
- Error responses: `400`, `401`, `403`, `409`, `500`, `501`, `503`.
